# Professional Portfolio Website

A responsive one-page portfolio created with HTML and CSS. It is ready to publish using GitHub Pages.

## Personalize before publishing

1. Update projects, skills, or contact information in `index.html` when needed.
2. Open `index.html` in a browser to preview your edits.

## Publish

Use the instructions in `outputs/Portfolio_Website_GitHub_Pages_Guide.pdf` to create a GitHub repository, push these files, and enable GitHub Pages.

Site URL - https://joshi75yash.github.io/portfolio-website/#home
